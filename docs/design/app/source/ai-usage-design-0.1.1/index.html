ai-usage — menu-bar app design

Final design handoff of the accepted 0.1.3 checkpoint. The primary target is the macOS popover overview, shown live below. Each card has a 7-day usage chart and every quota window that can limit usage. Other targets cover provider details, the history window, every review state, and the menu-bar icons.

⚠︎Illustrative sample data. Every number, time, model name, and price in these screens comes from app/fixtures.js. None of it is real usage. The reference clock is fixed at Tue 29 Sep 2026, 10:40.
