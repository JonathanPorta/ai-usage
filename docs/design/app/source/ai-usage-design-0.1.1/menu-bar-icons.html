Menu-bar icon states

One monochrome template glyph (the activity line from the app mark). State is carried by a small badge shape in the lower-right, so it reads without color and macOS can tint it for light, dark, and tinted menu bars.

Rules

  • Priority when several apply: collecting (while a check runs) > stopped > attention > paused > normal. A one-time check while the collector is stopped also shows “collecting”, then returns to “stopped”.
  • “Attention” means service trouble: a failed or partly failed check, or a provider that needs sign-in. A provider reaching its usage limit does not badge the icon — that is shown in the popover and, optionally, as a notification.
  • A stale reading alone does not trigger attention. Normal idle time between checks is healthy.
  • The collecting arc rotates at about one turn per second; with Reduce Motion it is shown static.
  • Each state sets the status item’s accessibility label (listed on each card), so VoiceOver announces it.
